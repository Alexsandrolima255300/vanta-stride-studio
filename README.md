# Vanta: Premium Sneakers

A ideia seria criar uma marca fictícia de sneakers, com identidade própria, mas usando como referência a experiência premium de lojas como a Nike: muito espaço visual, tipografia forte, cards grandes, animações suaves e navegação extremamente limpa.

👟 Projeto: VANTA — Premium Sneakers
